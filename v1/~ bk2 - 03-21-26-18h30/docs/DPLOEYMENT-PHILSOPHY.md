# SYZYGY.VOID Roadmap

## Purpose

This file tracks the approved direction of the site after the current stable baseline.

The roadmap should follow the real project order and not assume unapproved features.

---

## Current Baseline

The site is stable now.

Working:
- Hero
- About
- Music
- Videos
- Gallery
- Merch
- Lightbox
- Mobile nav
- UTM helper for tracks and videos

The roadmap begins from this stable point.

---

## Next Actual Feature

## 1. Contact Section

Contact is the next real build target.

Expected goals:
- section anchor `#contact`
- heading
- intro copy
- contact form
- newsletter checkbox
- submit button
- optional direct contact/social block

General approach:
- keep styling consistent with the rest of the site
- do not disturb working sections
- implement surgically

---

## After Contact

## 2. Back-to-Top Button

Planned behavior:
- fixed position
- bottom right
- visible when useful
- consistent styling with site design
- should feel native to current theme, not generic

---

## 3. Floating Newly Published Promo Module

Planned behavior:
- fixed position
- bottom left
- modular/data-driven
- can display:
  - image
  - title
  - description
  - CTA
- should be suitable for newly published content

Approved concept direction:
- may support a randomized batch/list mode
- may rotate through a set of promo items
- should remain structurally clean and controllable

---

## 4. Dedicated Lyrics Architecture / Page System

Planned scope:
- main lyrics index
- release sub-list
- individual lyrics pages

This should eventually become a real content architecture, not a hacked-on afterthought.

The lyrics system should fit the broader long-term CMS direction.

---

## Longer-Term Direction

## 5. Evolve Toward CMS-Like Structure

The current site is intentionally modular already.

Later work may evolve it further into a CMS-like structure where:
- content becomes easier to manage
- repeated patterns become more data-driven
- new releases/content types become easier to add
- larger scale maintenance becomes cleaner

---

## 6. Possible SaaS / Resellable Framework Direction

Longer term, the current project architecture may inspire or evolve into:
- a reusable framework
- a white-label foundation
- a SaaS/resellable direction

This is not the immediate implementation priority, but it is part of the long-range thinking.

---

## CMS-Phase Enhancement

## 7. Hero Evolution From Image to Video

Future idea:
- current hero is image-based
- later, in CMS phase, hero may evolve into video

Important:
this is later work, not current work

Current goal remains:
preserve the stable hero while building the next approved features.

---

## Roadmap Priority Summary

In order:

1. Contact section
2. Back-to-top button
3. Floating bottom-left newly published promo module
4. Lyrics system
5. CMS-like evolution
6. Possible SaaS/reusable framework direction
7. Hero video during CMS phase

---

## Rules For Roadmap Work

- do not skip ahead by breaking stable sections
- do not let future ideas justify present instability
- implement one layer at a time
- finish and stabilize before expanding
